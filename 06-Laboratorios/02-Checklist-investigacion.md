# Checklist operativo SOC

- [ ] Regla, evento original y marca temporal identificados.
- [ ] Zona horaria y rango de consulta comprobados.
- [ ] Fuente, parser y cobertura revisados.
- [ ] Entidades: usuario, host, IP, proceso, hash, según el caso.
- [ ] Contexto anterior y posterior investigado.
- [ ] Posibles explicaciones legítimas consideradas.
- [ ] Observación, inferencia y conclusión separadas.
- [ ] Limitaciones de visibilidad documentadas.
- [ ] Escalado o cierre conforme a procedimientos autorizados.
