# Glosario para analistas

| Concepto | Explicación |
|---|---|
| Telemetría | Datos observados por sensores y sistemas |
| Dataset | Conjunto de registros consultables |
| Preset | Acceso preparado a una consulta o grupo de datos |
| XDM | Modelo común para campos y eventos |
| XQL | Lenguaje para consultar y transformar registros |
| `filter` | Selecciona filas |
| `fields` | Selecciona columnas |
| `comp` | Agrega información por grupos |
| `join` | Une resultados de dos consultas |
| IOC | Indicador conocido de interés |
| BIOC | Indicador basado en comportamiento |
| Correlation Rule | Lógica de detección basada en correlación |
| Tuning | Ajuste de condiciones para mejorar calidad |
| Drill-down | Acceso a detalles de investigación |
